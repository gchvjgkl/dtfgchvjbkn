# Sanaei / 3x-ui برای Railway

این بسته یک استقرار ساده از 3x-ui رسمی Sanaei برای Railway است.

## Deploy

1. فایل ZIP را Extract کن.
2. محتویات را در GitHub قرار بده یا مستقیم به Railway وصل کن.
3. Railway را روی Repository بگذار تا Dockerfile را تشخیص دهد.
4. بعد از Deploy، در Railway برای سرویس یک **Volume** بساز:
   - Mount Path: `/etc/x-ui`
   این کار برای نگه‌داشتن دیتابیس و تنظیمات پنل ضروری است.
5. در Settings > Networking یک **Public Domain** برای سرویس بساز.
6. پنل از متغیر `PORT` خود Railway استفاده می‌کند؛ لازم نیست PORT را دستی تعیین کنی.
7. مسیر پنل عمداً `/` است؛ یعنی path اضافی ندارد.

## نکته مهم درباره Xray روی Railway

Railway برای ترافیک ورودی، پورت‌های عمومی مشخصی را در اختیار سرویس می‌گذارد. این بسته فقط خود پنل را آماده می‌کند و تضمین نمی‌کند که همه پورت‌های Inbound دلخواه Xray روی Railway قابل دسترسی باشند.

اگر هدف تو اجرای Xray/Proxy است، باید پورت موردنظر را طبق امکانات Networking/TCP Proxy همان پروژه Railway منتشر کنی.

## امنیت

بعد از اولین ورود:
- نام کاربری و رمز را عوض کن.
- 2FA را فعال کن.
- اگر لازم داری، بعداً یک web base path طولانی و تصادفی تنظیم کن.

این بسته بر پایه image رسمی:
ghcr.io/mhsanaei/3x-ui:latest

ساخته شده است.
